Global action

Take the campaign global

Smart glasses are a global problem, so Stop Smart Glasses has been built to travel.

We've made the campaign open source so people in other countries can use what we've already built rather than starting from scratch. You can adapt the campaign for your country, add your own retailers, laws, political routes and local actions, and launch Stop Smart Glasses where you live.

You do not need to be a developer to get involved.

If you want to launch a local version, the open-source project contains the website, campaign structure and technical resources needed to get started.

View the open-source campaign on GitHub →

  • Retailer contact routes
  • Political action
  • Petition links
